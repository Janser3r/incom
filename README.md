# Sitio web INCOM

Landing corporativa estática, responsive y sin dependencias, publicada mediante GitHub Pages en `incom.ramosapps.com`.

Incluye navegación móvil, portafolio de servicios y proyectos, formulario conectado a WhatsApp, enlaces de teléfono/correo, SEO, Open Graph, datos de rastreo y accesibilidad básica.

GitHub Pages publica la rama `main` desde la raíz del repositorio. El archivo `CNAME` vincula el dominio personalizado. No necesita instalación ni compilación.
