# Sitio web INCOM

Landing corporativa estática, responsive y sin dependencias, preparada para `incom.ramosapps.com`.

Incluye navegación móvil, portafolio de servicios y proyectos, formulario conectado a WhatsApp, enlaces de teléfono/correo, SEO, Open Graph, datos de rastreo y accesibilidad básica.

Para publicar, sube todos los archivos de esta carpeta —incluida `assets`— a la raíz pública del subdominio. No necesita instalación ni compilación.
